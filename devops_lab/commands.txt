У чому принципова різниця між Образом (Image) та Контейнером (Container)?

Image — це готовий шаблон, який містить усе необхідне для запуску програми. Container — це запущений екземпляр цього образу. Один Image можна використовувати для створення декількох контейнерів.

Що означає параметр -p 8080:80 у команді docker run і чому без нього браузер не побачив би сайт?

Параметр -p 8080:80 підключає порт 8080 комп'ютера до порту 80 контейнера. Порт 80 використовується веб-сервером Nginx. Завдяки цьому при відкритті localhost:8080 браузер може отримати сайт із контейнера.

Що означає крапка «.» в кінці команди docker build?

Крапка . означає поточну папку як контекст для створення образу. Docker шукає в цій папці Dockerfile та файли, які використовуються під час його виконання, наприклад index.htm
